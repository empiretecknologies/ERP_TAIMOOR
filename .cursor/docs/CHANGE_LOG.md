## 2026-09-08

### Changed
- Made SalesQutation item Rate editable on the item card
- `Empire_ERP/Views/SalesQutation/Index.cshtml`
- `Empire_ERP/wwwroot/js/Customjs/empr_SalesQutation.js`

### Reason
- User needs to change the item rate before or after selecting Qty

### Impact
- Rate is an input on each card; editing it does not increment Qty
- The edited rate is stored on the JavaScript detail list and saved with existing Detail CRUD

## 2026-09-08

### Changed
- SalesQutation item selection now uses a JavaScript detail list instead of a visible detail grid
- `Empire_ERP/Views/SalesQutation/Index.cshtml`
- `Empire_ERP/wwwroot/js/Customjs/empr_SalesQutation.js`

### Reason
- Requested POS-style card clicks (Qty starts at 0, no Add button) while keeping existing Master/Detail save

### Impact
- Clicking an item card increments Qty and updates `selectedItems`; group changes keep selected quantities
- Modal Save still posts Master + Detail to `/SalesQutation/Save` using `iteM_CODE`, `qty`, and `rate`

### Notes
- ADO.NET transaction and table structure were not changed
- A minus control on selected cards reduces Qty; Qty 0 removes the line from the list

## 2026-09-08

### Changed
- Redesigned SalesQutation form UI to a POS-style group/item card layout with a save modal
- `Empire_ERP/Controllers/SalesQutationController.cs`
- `Empire_ERP/Views/SalesQutation/Index.cshtml`
- `Empire_ERP/wwwroot/js/Customjs/empr_SalesQutation.js`

### Reason
- Requested a modern, responsive Sales Quotation UI that reuses Old POS Item Group → Items loading while keeping existing Master/Detail CRUD

### Impact
- Users select an item group, add items from cards into the existing detail grid, then Save opens a modal (Voucher No, Date, Party, Remarks) that posts to the existing `/SalesQutation/Save` action
- Item groups/items are loaded through `IPOSTransactionService` from the SalesQutation controller so the current menu `Code` is preserved

### Notes
- Save SQL, voucher numbering, and ADO.NET transaction behavior were not changed
- Missing item/group images fall back to a Font Awesome placeholder
- Razor CSS media queries in the view use `@@media` so the form compiles

## 2026-09-08

### Changed
- Updated SalesQutation detail CRUD to include `RATE`
- `Empire_ERP.Core/Entities/SalesQutationDetail.cs`
- `Empire_ERP.Infrastructure/Repositories/SalesQutationRepository.cs`

- Amount column is display-only (`allowEditing: false`)
